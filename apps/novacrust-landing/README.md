# Novacrust landing page

Static, no-build, mobile-first landing page. Open `index.html` or serve the folder:

```bash
npx serve apps/novacrust-landing
```

## Placeholders to replace before launch

- `app.js` `CONFIG`: sample rate (NGN per USDC), fee rate, promo threshold.
- `index.html`: median payout time (`~15 min`), supported networks (FAQ), and the CTA `href="#"` (all
  elements with `data-cta`).
